# Inner Compass 세션 플로우 명세

> **정식 참조 문서.** 이 문서는 `/reflect`, `/reflect-quick`, `/reflect-deep` 명령의 세션 플로우를 규정합니다.
> `spec-commands.md` 등 다른 명세에서 플로우를 언급할 때 이 문서를 교차 참조합니다.
>
> 소스 오브 트루스: `commands/reflect.md` (표준 플로우), `commands/reflect-quick.md`, `commands/reflect-deep.md` (모드 변형)

---

## 전체 플로우 다이어그램

```
~/.inner-compass/config.md
         │
         ▼
┌─────────────────────────────────────────┐
│  Pre-phase: Context 로드                │
│  ├─ 마이그레이션 확인                   │
│  │    patterns.md → roots.md 변환 여부  │
│  ├─ roots.md 로드                       │
│  └─ 최근 세션 나침반 + state 로드       │
└────────────────────┬────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────┐
│  Phase 0: 수집                          │
│  inner-compass-collector                │
│  ($ARGUMENTS → 첫 번째 생각, 최소 3개) │
└────────────────────┬────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────┐
│  Phase 1: 탐색                          │
│  inner-compass-socratic                 │
│  (생각 + roots.md + 최근 나침반 전달)  │
│  2–3라운드 질문·답변 반복               │
└────────────────────┬────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────┐
│  Phase 2: 결정화                        │
│  inner-compass-crystallizer             │
│  (원본 생각 + 대화 기록 + roots.md 전달)│
│  뿌리 매칭 분석 포함하여 반환          │
└────────────────────┬────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────┐
│  Phase 2.5: 리뷰 분기                   │
│  (1) 저장  ───────────────────────────►│
│  (2) 수정 → crystallizer 수정 모드 ─►  │
│  (3) 새 생각 → socratic 2차 탐색 ────► │
│               (Phase 2로 재진입)        │
└────────────────────┬────────────────────┘
                     │ (1) 선택 시
                     ▼
┌─────────────────────────────────────────┐
│  Phase 3: 저장 및 완료                  │
│  ├─ 세션 파일 저장 (YYYY-MM-DD-HHmm.md)│
│  └─ roots.md 갱신                       │
└─────────────────────────────────────────┘
```

## Pre-phase: Context 로드

세션이 시작되면 가장 먼저 `~/.inner-compass/config.md`를 읽어 세션 저장 경로를 확인합니다. 설정 파일이 없으면 `/reflect-setup`을 먼저 실행하도록 안내하고 종료합니다.

### 마이그레이션 확인

세션 저장 경로에서 아래 규칙에 따라 파일 상태를 판단합니다.

| 상태 | 처리 방식 |
|------|-----------|
| `roots.md` 없음, `patterns.md` 있음 | `patterns.md` → `roots.md`로 변환 후 진행. `patterns.md`는 보존(삭제하지 않음) |
| `roots.md`와 `patterns.md` 둘 다 있음 | `roots.md`만 사용, `patterns.md` 무시 |
| 둘 다 없음 | 첫 세션으로 간주, 빈 상태로 진행 |

**변환 필드 매핑 (`patterns.md` → `roots.md`):**

| patterns.md 필드 | roots.md 필드 | 비고 |
|------------------|---------------|------|
| 패턴명 | 뿌리 이름 | |
| 설명 | 메모 | |
| 관련 세션 수 | 등장 횟수 | |
| (없음) | 표면 변형 | 빈 리스트로 초기화 |
| (없음) | 추이 | `"관찰 중"`으로 초기화 |

### roots.md 로드

세션 저장 경로의 `roots.md`를 읽습니다.

- 파일이 없으면 빈 상태로 진행합니다.
- 파싱 불가능하면 빈 상태로 취급하고, 세션 파일에 경고를 기록합니다.

### 최근 세션 로드

세션 저장 경로에서 가장 최근 세션 파일 1개를 읽습니다.

- 모드(standard / quick / deep) 무관하게 가장 최근 파일을 선택합니다.
- 나침반 섹션이 없는 경우 그 다음 최근 파일로 폴백합니다.
- 추출 대상: **나침반 섹션** + **state(상태 명명)**

## Phase 0: 수집

`inner-compass-collector` 에이전트에 위임하여 사용자의 생각 조각을 수집합니다.

- `$ARGUMENTS`가 있다면 첫 번째 생각으로 사용합니다.
- 사용자에게 다음과 같이 안내합니다:

  > "지금 머릿속을 떠도는 생각, 걱정, 감정을 자유롭게 말해주세요.
  > 정리할 필요 없습니다. 떠오르는 대로 하나씩."

- **최소 3개**의 생각이 모이면 다음 단계를 제안합니다.
- 사용자가 "됐어", "이 정도면", "다 적었어" 등의 종료 신호를 주면 수집을 마칩니다.

---

## Phase 1: 탐색

`inner-compass-socratic` 에이전트에 위임합니다. 아래 형식으로 컨텍스트를 전달합니다:

```
다음은 수집된 생각 조각들입니다:
1. ...
2. ...

[과거 맥락]
{roots.md 내용, 없으면 이 섹션 생략}

[최근 세션 나침반]
{최근 세션의 state + 나침반 섹션, 없으면 이 섹션 생략}

이 생각들을 분석하고 소크라테스식 질문을 생성해주세요.
과거 맥락이 있다면 반복되는 뿌리나 변화에 대한 질문도 포함해주세요.
```

에이전트가 반환한 질문 중 **2–3개**를 사용자에게 제시합니다. 사용자 답변 → 통찰 반영 → 후속 질문 순서로 **2–3라운드** 반복합니다.

---

## Phase 2: 결정화

`inner-compass-crystallizer` 에이전트에 위임합니다. 아래 형식으로 컨텍스트를 전달합니다:

```
다음은 전체 탐색 기록입니다:

[원본 생각]
1. ...

[대화 기록]
Q: ...
A: ...

[과거 맥락]
{roots.md 내용, 없으면 이 섹션 생략}

[저장 설정]
세션 저장 경로: {경로}
모드: standard

이 전체 맥락을 종합하여 상태를 결정화해주세요.
roots.md의 기존 뿌리와 매칭 분석을 포함해주세요.
```

crystallizer는 결정화 결과와 `[roots_update]` 구조화된 뿌리 매칭 분석을 반환합니다. **파일 저장이나 roots.md 갱신은 이 단계에서 수행하지 않습니다.**

---

## Phase 2.5: 리뷰 분기

crystallizer가 반환한 결정화 결과를 사용자에게 보여줍니다. 이후 다음과 같이 안내합니다:

> "결정화가 완료되었습니다. 어떻게 할까요?
>
> (1) 괜찮아요, 저장해주세요
> (2) 수정하고 싶어요
> (3) 새로운 생각이 떠올랐어요"

### (1) 저장

Phase 3으로 진행합니다.

### (2) 수정 모드 — crystallizer 재호출

사용자에게 수정하고 싶은 부분을 먼저 물어봅니다. 이후 `inner-compass-crystallizer`를 수정 모드로 호출합니다:

```
수정 모드로 전환합니다.

[이전 결정화 결과]
{결정화 결과 전체}

[사용자 피드백]
{사용자가 말한 수정 요청}

이전 결과에서 사용자가 지적한 부분만 수정해주세요.
```

수정된 결과를 받아 **리뷰 분기(Phase 2.5)로 돌아갑니다.** (루프 가능)

### (3) 2차 탐색 — socratic 재호출

사용자에게 새로 떠오른 생각을 자유롭게 말하게 합니다. 이후 `inner-compass-socratic`을 2차 탐색 모드로 호출합니다:

```
2차 탐색 모드로 전환합니다.

[원본 생각]
{1차 수집 결과}

[1차 대화 이력]
{Phase 1의 전체 대화}

[결정화 결과]
{현재 결정화 결과}

[새로운 생각]
{사용자가 추가로 말한 내용}

[과거 맥락]
{roots.md 내용, 없으면 생략}

결정화 결과를 바탕으로 새로운 생각을 탐색해주세요.
이미 1차에서 다룬 질문은 반복하지 마세요.
```

2차 탐색이 완료되면 **Phase 2(결정화)로 재진입**합니다. 이때 crystallizer에 전달하는 대화 기록에 2차 탐색 내용도 포함합니다. 결정화 후 다시 **Phase 2.5(리뷰 분기)로 돌아갑니다.**

---

## Phase 3: 저장 및 완료

### 세션 파일 저장

결정화 결과를 세션 파일로 저장합니다.

- 파일명: `YYYY-MM-DD-HHmm.md` (현재 날짜와 시간)
- 저장 경로: config에서 확인한 세션 저장 경로

리뷰 분기에서 수정이 발생한 경우 frontmatter에 아래 항목을 추가합니다:

```yaml
revised: true
revision_count: {수정 횟수}
revision_history:
  - type: correction | exploration
    trigger: "{사용자가 말한 수정/탐색 계기 요약}"
```

### roots.md 갱신

crystallizer가 반환한 `[roots_update]` 분석을 기반으로 `roots.md`를 갱신합니다. **갱신은 최종 수락된 결과 기준으로 한 번만 수행합니다.**

갱신 방식은 `roots.md` 전체를 읽고 업데이트된 버전을 구성한 뒤 전체 파일을 다시 씁니다.

| 분류 | 처리 방식 |
|------|-----------|
| `matched` | 해당 뿌리에 표면 변형 추가, 추이 갱신, 등장 횟수 증가, 관련 세션 링크 추가 |
| `new` | 새 뿌리로 등록 (추이: `"관찰 중"`) |
| `ambiguous` | 세션 frontmatter에 `연관 가능: {뿌리명}` 표시. 2회 연속 세션에서 같은 연관 감지 시 매칭으로 승격. 3회 세션 동안 재등장하지 않으면 연관 표시 삭제 |
| `resolved` | 해소된 뿌리 섹션으로 이동, 해소 계기 기록 |

`roots.md`가 손상되었거나 파싱 불가능하면 빈 상태로 취급하고 세션 파일에 경고를 기록합니다.

### 완료 안내

저장 완료를 사용자에게 알립니다. 궤적 섹션에서 반복 중인 뿌리가 있으면 간략히 언급합니다.

## 모드별 변형

| 항목 | `/reflect` (standard) | `/reflect-quick` | `/reflect-deep` |
|------|----------------------|------------------|-----------------|
| **Phase 0: 수집** | O (최소 3개) | 생략 — `$ARGUMENTS` 또는 단일 입력 | O (최소 5개 권장) |
| **Phase 1: 탐색 라운드** | 2–3라운드 | 1라운드 (질문 1개, 답변 1회) | 5라운드 이상 |
| **탐색 강도** | 표준 | 간략 진단 | 존재론적 분석 강화, "증상 vs. 원인" 질문 집중 |
| **Phase 2: 결정화 모드** | `standard` | `quick` | `deep` |
| **deep 추가 분석** | — | — | 시간축 분석(과거→현재→미래), 가치관 충돌 맵 |
| **Phase 2.5: 리뷰 분기** | O | 생략 | O (2차 탐색 시 5+ 라운드) |
| **세션 파일명** | `YYYY-MM-DD-HHmm.md` | `YYYY-MM-DD-HHmm-quick.md` | `YYYY-MM-DD-HHmm-deep.md` |
| **roots.md 갱신** | O (전체) | O (반복 뿌리만 표시) | O (전체 + 시간축 분석 포함) |
| **궤적 섹션** | O | 간략 — 반복 뿌리만 표시 | O (전체 + 시간축 분석) |
| **마이그레이션 확인** | O | O (`/reflect`와 동일) | O (`/reflect`와 동일) |
